RSA Cryptography

RSA (Rivest–Shamir–Adleman) is an asymmetric cryptosystem. Security is based on the computational hardness of factoring large integers.

Key generation: N = p·q (p, q prime)
Encrypt: C = Mᵉ mod N
Decrypt: M = Cᵈ mod N
Sign: S = Mᵈ mod N
Verify: M = Sᵉ mod N

We use 2048-bit keys (p, q each 1024 bits), providing approximately 112 bits of security.

Blind Signatures

Invented by David Chaum (1982). Allows a signer to sign a message without seeing its content — like signing a carbon-copy inside a sealed envelope.

Choose random blinding factor r
Blind: B = rᵉ · M mod N (sent to CTF)
CTF signs: S_B = Bᵈ mod N
Unblind: S = S_B · r⁻¹ mod N
Verify: Sᵉ mod N = M ✓

The CTF never sees M (the vote). Yet S is a valid signature on M.

CTF — Central Tabulating Facility

The CTF is the trusted authority that issues blind signatures, proving a voter is eligible without learning which candidate they chose.

  • Maintains a registry of approved voters
  • Refuses to sign twice for the same voter key
  • Verifies voter authentication via their own key
  • Never stores or sees the actual vote
  • Publishes its public key so anyone can verify

Verification Authority

The VA is a separate, independent server that receives anonymous ballots and validates them using only the CTF's public key.

  • Receives votes with no voter identity attached
  • Verifies CTF signature on vote+nonce hash
  • Rejects any ballot with a repeated nonce
  • Maintains the live vote tally
  • Cannot link any vote to any registered voter

Replay Attack Protection

A replay attack occurs when an adversary captures a valid ballot and re-submits it to inflate a candidate's count. We prevent this with UUID nonces.

nonce = uuid4() (128-bit random)
M = SHA-256( vote || ":" || nonce )
VA stores: usedNonces = set()
If nonce ∈ usedNonces → REJECT

The nonce is hashed into the signed message, so it cannot be changed post-signing.

SHA-256 Hashing

Before blinding, the vote+nonce string is hashed with SHA-256, producing a fixed 256-bit integer. This is what the CTF actually signs.

Input: "3:a8f2c1d0-..." (vote:nonce)
Output: 256-bit integer (as big int)
Then blinded → signed by CTF
  • Collision-resistant: can't find two votes with same hash
  • Pre-image resistant: can't reverse from hash to vote
  • Fits within RSA modulus for signing
Complete Voting Protocol — Step by Step
01
Register: Voter generates (e_v, d_v, N_v). Sends (e_v, N_v) to CTF. CTF returns (e_ctf, N_ctf).
02
Nonce: nonce = uuid4(). combined = f"{vote}:{nonce}". M = SHA-256(combined) as integer.
03
Blind: Pick random r coprime to N_ctf. B = rᵉ_ctf · M mod N_ctf.
04
Auth sign: auth_sig = B^d_v mod N_v. Proves voter identity to CTF without revealing the vote.
05
CTF signs: CTF verifies auth_sig, checks not double-voting. Signs: S_B = B^d_ctf mod N_ctf.
06
Unblind: S = S_B · r⁻¹ mod N_ctf. Now S is a valid CTF signature on M.
07
Local verify: Assert S^e_ctf mod N_ctf == M. Confirms the signature is genuine.
08
Cast: Send (vote, nonce, S) to VA — no voter identity. VA verifies S and nonce uniqueness, tallies.
