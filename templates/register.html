Why Registration Matters
Authentication Without Identity

The CTF knows you are a legitimate voter (via your public key) but will never know which candidate you voted for.

One Registration = One Blind Signature

The CTF tracks registrations by public key and refuses to sign a second ballot for the same key.

2048-bit RSA Security

Key generation uses cryptographically secure prime generation — equivalent to ~112 bits of symmetric security.

Key Generation
p, q → large random primes (1024-bit each)
N = p·q → 2048-bit modulus (public)
φ(N) = (p−1)(q−1) → Euler's totient
e → random, gcd(e, φ) = 1 (public exponent)
d = e⁻¹ mod φ → private exponent (never sent)
